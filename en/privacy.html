Privacy notice

Last updated: 7 October 2026

SkyNet is a personal assistant for private use, run by Mattia Bellini for himself. It is not a service offered to the public and has no other users. This page describes what data it handles and how.

Google account data

When the owner connects his account, SkyNet asks Google for a single permission: managing Google Calendar events. With that permission it can:

  • read events, to show the agenda and avoid clashes;
  • create and edit events, at the owner's explicit request.

SkyNet does not request access to other Google services through this application.

How it is used

Calendar data is used only to carry out the owner's requests: answering questions about the agenda, adding events, setting reminders. It is not used for advertising, profiling or analytics, and it is not sold.

Where it stays

Access credentials and the request history are kept on the owner's private server. To process a request, its content may be sent to an artificial intelligence model, local or from an external provider, solely to obtain the answer.

Sharing

Data is not shared with third parties, except as described above for processing a request or where required by law.

Revoking access

Access can be revoked at any time from the Third-party access page of the Google account. From that moment SkyNet can no longer read or edit the calendar.

This site

The site is static and hosted on GitHub Pages. It uses no cookies, no analytics tools and no third-party resources. GitHub, as the hosting provider, may log technical visit data such as the IP address, under its own policies.
